# Open PolyForge user requirements

What the users in OPF-PRB-001 need, written from their side. Priorities are proposals for review with the Helpful Engineering project team.

Table 1. User requirements.

| ID | Category | Title | Need | Priority | Source |
| --- | --- | --- | --- | --- | --- |
| UR-001 | Performance | Fine-fibre web | The machine must make a melt-blown PP web with fibres in the filtration range of about 1 to 5 um | High | Proposal; test partner (U4) |
| UR-002 | Performance | Charged web | The web must be charged electrostatically, and we must be able to tell that the charge is there | High | Proposal; U4 |
| UR-003 | Deployment and assembly | One wall outlet | It must run from one standard 120 V outlet, ideally a 15 A circuit, at most 20 A | High | Proposal; maker-space lead (U1) |
| UR-004 | Deployment and assembly | One bench | It must fit a 2 ft x 8 ft workbench | High | Proposal; U1 |
| UR-005 | Deployment and assembly | Buildable locally | We must be able to build it from commonly available parts, with high-precision machining only for the die | High | Proposal; machinist (U2) |
| UR-006 | Performance | Consistent web | The web must be consistent in basis weight and fibre size from run to run | High | Proposal metrics; U4 |
| UR-007 | Performance | Useful output | It should make enough web per hour for test lots and small-lot downstream trials | Medium | Proposal metrics; planner (U5) |
| UR-008 | Safety | Safe to run | Hot surfaces, high voltage, mains and moving parts must be guarded, with interlocks and an emergency stop | High | Proposal; operator (U3); Helpful Engineering |
| UR-009 | Safety | Fumes and ozone controlled | Fumes from hot PP and ozone from charging must be captured and kept below workplace limits | High | Proposal environment; U3 |
| UR-010 | Usability | Standard controls | Controls must use standard heaters, thermocouples, PID loops, steppers and embedded electronics | Medium | Proposal |
| UR-011 | Usability | Documented | Build, operating and maintenance documentation must let a capable team not involved in the design reproduce and run it | High | Proposal deliverable 2; U1 |
| UR-012 | Performance | Measurable web | We must be able to measure the web's efficiency at about 0.3 um and its pressure drop by standard methods | High | Proposal metrics; U4 |
| UR-013 | Regulatory | Honest claims | Claims must be honest: the machine makes media, not respirators | High | Proposal regulatory section; Helpful Engineering |
| UR-014 | Cost | Affordable | A maker space or NGO must be able to fund one machine | Medium | Proposal (funding not yet defined); U5 |
| UR-015 | Maintenance | Maintainable | The die and melt path must be purgeable and cleanable, with spare parts available | Medium | U3 |
| UR-016 | Logistics | Standard resin | It must run on a commercially available melt-blown PP grade | Medium | Proposal; plastics volunteers |
